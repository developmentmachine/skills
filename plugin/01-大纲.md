# Plugin 大纲

**题目：** Plugin 的基础、进阶、高级使用  
**时长：** 45 分钟  
**前提：** 听众知道 skill 是带 `SKILL.md` 的文件夹，描述负责被选中，正文按需加载。

## 听众离开时要能做

1. 基础：写出一个只有 `plugin.json` 和一份 skill 的包，并知道在 ChatGPT / Codex 里安装后怎么调用。
2. 进阶：把「怎么做」留在 skill，把「连到哪个系统」留在 `mcp.json`，并预期某个服务失败时其余部分仍在。
3. 高级：把只对某一个客户端有意义的钩子、界面和配置放进反向域名扩展，而不是写进可移植清单。

## 基础（12 分钟）

目标：会用别人装好的插件，也会打出一个最小包。

- Plugin 是目录。它搬运 skill 和 MCP，不取代 `SKILL.md` 的写法。
- 只有一份 skill、且只在一个地方用时，直接发 skill 目录。多份材料要一次装上、换客户端还能被找到时，再打成插件。
- 最小清单只有 `$schema` 和 `name`。skill 放在 `skills/<名字>/SKILL.md`。客户端只扫 `skills/` 的直接子目录，不递归。
- ChatGPT 与 Codex 共用公开插件目录。装完后新开对话，直接说任务，或用 `@` 点名插件 / 其中的 skill。Codex CLI 用 `/plugins`。IDE 扩展里没有插件。

打开 `examples/plugins/01-basic/hello-plugin/`。

## 进阶（16 分钟）

目标：会把一个工作流拆成「手册 + 工具」，并写成规范承认的 `mcp.json`。

- 一个插件里可以有多份 skill。每份仍然靠自己的 description 被选中。
- MCP 提供实时数据、身份、权限和受控动作。Skill 规定何时调用、顺序、结果不全时怎么办、交付物长什么样。
- `mcp.json` 里每个服务必须写 `type`：`stdio`、`streamable-http`，或可选的旧式 `sse`。客户端按声明的类型连，没有自动改走另一种传输。
- 包内路径以 `./` 开头。`command` 是一个可执行文件名，不是一条 shell 命令。`${PLUGIN_ROOT}` 指向包本身，`${PLUGIN_DATA}` 指向客户端为这个已安装实例准备的可写目录，更新包时保留。
- 某条 MCP 起不来、握手失败、或传输不被这个客户端支持时，客户端跳过它，继续加载其他服务和 skill。

打开 `examples/plugins/02-intermediate/status-pack/`。说明占位进程会失败，skill 目录仍然有效。

## 高级（15 分钟）

目标：知道可移植边界，避免把客户端私货写进核心清单。

- v1 的可移植组件只有 skill 和 MCP。钩子、命令、子代理、规则、自定义界面不在核心格式里。
- 客户端私有配置放 `plugin.json` 的 `extensions.<反向域名>`，文件放同名的顶层目录，例如 `com.example.client/`。不认识这个名字的客户端整段忽略。
- OpenAI 自己的展示信息、已注册 MCP 映射和钩子，放在 `extensions` 的 OpenAI 名空间。旧的 `.codex-plugin/plugin.json` 仍是兼容布局。`@plugin-creator` 搭出来的默认是兼容布局；要可移植包，用根上的 `plugin.json` 和 `mcp.json`。
- Codex 钩子是生命周期命令，安装前要按哈希信任。插件钩子在云端编排的 ChatGPT Work 里不可用。在网页上安装插件，不会把钩子脚本部署到执行环境。
- 规范不管安装器、市场、权限模型和沙箱。ChatGPT / Codex 用统一目录和 marketplace 做分发；发现协议、目录条目和包格式是三层，用一层不强制用下一层。
- `$schema` 是协议版本，两份 JSON 必须一致。`version` 是可选标签，供更新检查和缓存新鲜度用，客户端可以不读。规范不规定选版本、升级或降级；换包是客户端替换目录，`PLUGIN_DATA` 保留。插件里的 skill 没有自己的版本。
- 密钥不写进 `headers` 或 `env`。远程地址除本机外使用 HTTPS。包内路径不能解析到插件根目录外面。

打开 `examples/plugins/03-advanced/reports-plugin/`，只指出扩展目录和两份传输声明。

## 可删

- 听众只想会装会点：讲完基础即可，进阶留「skill 写流程、MCP 提供工具」一页。
- 听众要自己发插件：基础压到 8 分钟，把高级里的 marketplace 和兼容布局讲满。
- 时间紧：删钩子细节和发现协议分层，高级收在扩展名空间和密钥两条。
