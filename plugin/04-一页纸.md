# Plugin 一页纸

## 和 skill、memory 的边界

做法用 skill，外部系统工具可通过 MCP 接入，跨对话事实用 memory。要把能力作为一个包安装、分享时用插件，不要求 skill 和 MCP 同时存在。Memory 不放进 `plugin.json`。

## 它是什么

Plugin 是带标准根 manifest 的自包含目录，可携带 skill、MCP 配置和客户端扩展。只有 skill、只有 MCP、两者都有都合法；只有 manifest 的空包也合法，但不提供任务能力。

v1 的固定位置：

```text
my-plugin/
├── plugin.json                   # 必需，唯一标准入口
├── skills/<skill-name>/SKILL.md   # 可选
├── mcp.json                      # 可选
└── com.example.client/           # 可选，客户端扩展
```

## 基础

最小清单：

```json
{
  "$schema": "https://agent-plugins.org/schemas/1.0.0/plugin.schema.json",
  "name": "hello-plugin"
}
```

`name`：1–64；`a-z`、`0-9`、`-`、`.`；首尾为字母或数字；不能有 `--` 或 `..`。

`skills/` 只发现直接子目录里的 `SKILL.md`。没有 `skills/` 或没有 `mcp.json` 都合法。

ChatGPT 与 Codex：在 Plugins 里安装，新开对话，直接说任务，或用 `@` 点名。Codex CLI 用 `/plugins`。IDE 扩展不提供插件。

一份 skill、只在当前项目用：不必打包。只连接一个 MCP 服务，也可用客户端原生配置；按 Agent Plugins 格式分发则仍需根 manifest，标准 `mcp.json` 不能单独替代它。

## 进阶

| Skill 说明 | MCP 服务与客户端 |
| --- | --- |
| 顺序、SQL 模板、验收与输出规则 | 实际工具调用、系统连接、认证与授权 |

SQL 可以在正文或参考文件中。`mcp.json` 只描述 MCP 服务的启动和连接；写出查询不等于获得执行能力。真实令牌和密码不进包。

`mcp.json` 每个服务必填 `type`：`stdio`、`streamable-http`，或可选的 `sse`。首次连接按声明的传输；后续回退由客户端决定，插件不能依赖未约定的回退。`command` 是单个可执行名或 `./` 路径，参数放 `args`。

| 变量 | 用途 |
| --- | --- |
| `${PLUGIN_ROOT}` | 包内只读文件 |
| `${PLUGIN_DATA}` | 可写状态，升级后保留 |

一条服务失败，其他服务和 skill 继续加载。清单的两个非致命例外是未知顶层字段、非对象 `extensions`，报告并忽略；其他清单错误拒绝整包。

## 高级

v1 的可移植组件只有 skill 和 MCP。扩展数据放 `extensions.<反向域名>`，扩展文件放同名顶层目录；本课 OpenAI 展示信息用根 manifest 的 `extensions.com.openai`。

OpenAI 插件钩子仅支持手动安装到 Codex desktop 的场景；含钩子的包不能进入公开插件目录，网页安装也不会部署钩子脚本。

`$schema` 是协议版本。`plugin.json` 与 `mcp.json` 必须相同，否则停用 MCP、保留 skill。客户端不认识这个版本就拒绝整包。

`version` 可选，是当前这份已安装目录的标签。客户端可以拿它判断更新和缓存，也可以不读。加载时不按它挑选。建议语义化：主版本是不兼容变更，次版本是向后兼容的新行为，修订号是修正。不像语义化版本，不能因此拒绝整包。它不启动替换，也不证明文件变了。

规范不规定升级或降级。客户端用另一份目录替换当前这份，`PLUGIN_DATA` 保留。插件里的 skill 没有自己的版本。

密钥不写入 `headers` 或 `env`。包内路径以 `./` 开头，且不能解析到插件根外面。

规范不规定安装、市场、权限和沙箱。公开目录、工作区 marketplace、个人 marketplace 是产品自己的分发层。

## 示例

| 档 | 路径 |
| --- | --- |
| 基础 | `examples/plugins/01-basic/hello-plugin/` |
| 进阶 | `examples/plugins/02-intermediate/status-pack/` |
| 高级 | `examples/plugins/03-advanced/reports-plugin/` |

`hello-plugin` 是最小 Skill 插件示例。`status-pack` 和 `reports-plugin` 只用来看目录：安装后不会得到活动数据或指标。`bin/activity` 与 `bin/validate` 会故意失败。`https://mcp.example.com/mcp` 不是这门课的服务。
