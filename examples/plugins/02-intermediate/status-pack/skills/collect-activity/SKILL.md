# 收集活动

## 工具

只使用本插件 MCP 里名为 activity 的工具。不要另写地址或令牌。

## 步骤

1. 向用户确认时间范围。没说时先问，默认不用「全部」。
2. 调用 activity，取回时间、对象、动作。
3. 工具不可用或返回为空时，停止并说明缺了哪一段，不要编造记录。
4. 把记录交回对话。需要简报时，再按 write-brief 的结构写。

## 完成前

- 每条记录都能对应到工具结果
- 时间范围写在结果开头
