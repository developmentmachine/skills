# PR 描述

没有基线分支时，先问，不要假设。

1. 只写改动里能看到的行为变化。
2. 与这次改动无关的背景不写。
3. 改动里没有的数字不要写。说不出来源就删掉。
4. 没跑过的测试写「未运行」，不要编造结果。

输出这三个标题：

### 摘要

每条一行，最多 5 条。

### 风险

没有就写「无」。

### 测试

已运行的写做了什么。没跑过就写「未运行」。

交出去之前：三个标题都在，没有整段 diff，没有改动里不存在的数字。
